# No Time To Sleep – refinement pass

## What changed
- Shortened and tightened the umbrella homepage.
- Gave TruBytes a distinct sub-brand treatment while keeping it within the No Time To Sleep design system.
- Shortened the Cold Chain page and focused it on problem → model → platform → validation.
- Replaced the contact-card layout with a structured enquiry form. The form currently prepares an email in the visitor's email app; it does not submit to a server.
- Added active navigation states.
- Standardised root-relative asset links.
- Added canonical URLs, Open Graph metadata, robots.txt, sitemap.xml and a custom 404 page.

## Deployment
Copy these files into the existing repository, then:

    git add .
    git commit -m "Refine branding pages and contact flow"
    git push

Cloudflare should deploy automatically from the connected GitHub repository.
