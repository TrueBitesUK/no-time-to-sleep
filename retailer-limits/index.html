Getting started

From rule to checkout

  1. Install and open Retailer Limits from Shopify Admin when available.
  2. Add a product quantity or cart weight rule, choose blocking behaviour and save.
  3. Activate the Retailer Limits checkout validation rule in Shopify settings.
  4. Optionally add the product and cart storefront blocks through the theme editor.
  5. Test a cart exceeding the limit to confirm the checkout message appears.
